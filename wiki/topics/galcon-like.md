## Definition

A subgenre of real-time strategy where the entire game collapses to: nodes (planets, towers, cells) that produce units automatically, players send units along connections to capture or reinforce, win condition is owning all non-neutral capacity.

There is no formal name. The community uses **node-based RTS** or **Galcon-like**, after Phil Hassey's *Galcon* (2006), which set the template. "Swarm Defense" surfaces occasionally but never stuck.

## Lineage

Galcon (2006) → Phage Wars (Flash Galcon clone) → Auralux (2011, abstracted further) → Tentacle Wars → NeoWars.

## flux's place

flux strips further: continuous strength rather than ship streams ([[continuous-flow-model]]), boolean toggles per ordered pair rather than fractional drains, hand-laid graph, two players, one dumb AI. The minimal version of the genre.
